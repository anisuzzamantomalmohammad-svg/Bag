# Bag

Personal money records for Android: expenses, income, transfers, I owe and Owed to me, in any currency. Budgets, goals, repeats with reminders, reports, Excel export and import, optional Google Drive sync, app lock and dark mode.

Built with Expo (SDK 54). See BUILD-STEPS.txt to build the APK on expo.dev.
