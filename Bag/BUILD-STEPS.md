# Building Bag 2.2

1. Upload the inside of this folder to the GitHub folder `Bag` (replace what's there).
2. On expo.dev: new Android build, base directory `/Bag`, profile `preview`, keep the existing keystore.
3. Version is 2.2.0, versionCode 6. Two new packages (expo-sensors, expo-battery) install on the build server; nothing to do.
4. Install over 2.1. Your records stay. Bag keeps a copy from before the update (Settings › Go back to before the last update).

After installing:
- Long-press the home screen › Widgets › Bag. Default size is 4×2. There's also a 2×2 "Bag jar".
- Settings › Money › Safety margin: turn it on and say yes to adding the 280 back, so Bank matches the ANZ app.
- Settings › Money › Paydays: pick your days.
